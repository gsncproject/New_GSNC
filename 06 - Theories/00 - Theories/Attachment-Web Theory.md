# Attachment-Web Theory 
(*This is a theory proposed in the 2025 GSNC Version „GSNC -- For real Now.pdf“*)

One entity/attachment can attach itself to multiple people at the same time but also interact with each individual separately at the same time. As if it would split itself but it doesn’t. Meaning the same entity/attachment is with different people at the same time.
